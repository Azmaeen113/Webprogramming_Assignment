## GitHub Pages Deployment

1. Go to repository **Settings**.
2. Open **Pages**.
3. Under **Build and deployment**, choose source: `Deploy from a branch`.
4. Select branch: `main` and folder: `/ (root)`.
5. Save and wait for the public link to appear.
